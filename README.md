# 🐈 냥냥 머지

고양이 캐릭터로 만든 수박게임류 머지 퍼즐. 같은 냥이끼리 합쳐서 **고등어(코리안숏헤어)**까지 키우는 게 목표.

**플레이:** https://jelly-arcade.pages.dev/nyang-merge/

> 옛 주소 `poikjuujk-cyber.github.io/nyang-merge/` 는 위 주소로 자동 이동합니다.

## 특징

- 🐾 11단계 고양이 — 아깽이부터 👑고등어까지 (전부 오리지널 캔버스 드로잉)
- 🔥 **콤보** — 짧은 시간에 연달아 합치면 최대 x3 배수
- 🐟 **츄르 대폭발** — 고등어 2마리가 만나면 판 전체가 터지며 대량 보너스
- ⚡ **피버 타임** — 머지 10번마다 15초간 점수 x1.5 · 아이템 확률 2배
- 🎁 **아이템 파밍** — 냥이에 가끔 선물이 붙고, 그 냥이를 합치면 획득 (제거 / 교환 / 승급)
- 📖 **도감** — 처음 만든 냥이를 해금, 못 만든 냥이는 ??? 실루엣
- 🏆 **랭킹** — 게임이 끝나면 이름을 넣어 등록, 전체 등수 확인
- 🎵 배경음악 · 냥 울음소리 (각각 끄고 켤 수 있음)
- 💾 자동 저장 — 창을 닫아도 이어서 플레이

모바일 세로 배치와 PC 가로 배치를 모두 지원한다.

## 기술

의존성 없는 단일 HTML 파일. 물리는 [matter.js](https://brm.io/matter-js/), 그래픽은 Canvas 2D 직접 드로잉,
사운드는 Web Audio로 합성(오디오 파일 없음), 랭킹은 Supabase.
